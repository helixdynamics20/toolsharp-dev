json-formatter — the invisible characters a whitespace cleanup misses

Copy JSON out of Jira, Confluence, or Word and it quietly picks up characters you cannot see. Plenty of formatters strip a stray non-breaking space for you — but a zero-width space is not whitespace at all, so a whitespace cleanup walks straight past it:

the input — there is a hidden character after the comma
{ "user": "Jane", ​"role": "admin" }
what JSON.parse says
Expected double-quoted property name in JSON at position 18 (line 1 column 19)
what this one says
Removed 1 zero-width character (U+200B) at line 1, col 19

Twenty-one of these get handled, and only outside string literals — so a non-breaking space that is genuinely part of your data is left exactly as you wrote it.
