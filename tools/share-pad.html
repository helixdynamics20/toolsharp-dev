// sharing options explained

  • 6-Digit Numeric Code — A super simple code (e.g. 482 195) that is easy to dictate or copy-paste. Data is securely stored temporarily in an anonymous Key-Value store.
  • Offline Fallback Link — A serverless link that compresses and serializes the entire text directly inside the URL hash. Perfect for sharing large or highly private keys offline.
  • 100% Client-Side Encryption option — No passwords or accounts are required. Standard data transfer is executed directly between your browsers.
