// about base64 encoding

  • Standard vs URL-Safe — Standard Base64 uses + and /, which can cause issues in URL query parameters or filenames. URL-safe Base64 swaps these with - and _ respectively, and strips the trailing padding character (=).
  • UTF-8 Unicode Support — Native browser btoa() and atob() fail on non-ASCII characters (like emojis or foreign alphabet scripts). This tool uses byte array conversion to guarantee robust Unicode serialization.
